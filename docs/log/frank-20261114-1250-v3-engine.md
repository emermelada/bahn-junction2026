# V3 engine: win by fleet cost, flat fee per gig, barrier on lateness (Sat 14 Nov 12:50 laptop)

**What we saw.** c3 declines 320-450 requests a week and gets 43-76 bookings a day, while dealers would sell ~670 cars at the
margin-optimal price and a world gives ~150 bookings a day (research/mechanics/MECHANICS.md). Its rising fee ladder teaches
drivers to wait (organisers' /how). Halal replaced the same parts and went from EUR 48.9k to 82.8k on the 12:00 board round.

**The idea.** `V3Desk` (src/spreadbot/v3.py) keeps the desk's books, notes, holds, restarts and rescue and replaces three decisions:
quote = max (price - fee - P(late) x (0.45 price + EUR 20 + barrier)) x P(win), every option at the same euro margin;
the barrier is EUR 300 x (late share / 4%)^4, capped x16; one flat fee per gig from {0.85..1.5} x typical minimising
fee + P(late) x late cost, with P(late) = our on-time model x Halal's booking curve; pairs 0.70x, sitting cars 0.85x, second look 6 h.

**The test.** Preset `v3` (= c3bprl + engine=v3, fee_open 1.0, no fee_rel, bundle_mult 0.7, relook 1.15). Smoke dev-07, then dev-07..18
paired with base-c3, then dev-43..54 and WAR.

**Numbers.** Offline only so far: tests/frank 14/14 with PRESET=v3; on the fixture week the V3 paths run with no ERR (the fixture's
drivers never book, so its barrier saturates; not a measure of volume).

**Keep or kill.** Pending the smoke.

## Results (Sat 12:42-12:50 laptop, dev-07..12, paired with c3 13,416 / 19,764 / 12,312 / 13,052 / 10,277 / 12,718)
- v3 (no prior): dev-07 EUR 3,537, 103 orders: 4 early wins read as an 88% week, the barrier saturated, Monday 241/252 declined.
- v3b (prior 40 at target, anchor 1.05): 7,064 / 16,979 / 4,160 / 11,718 / 4,534 / 9,145; dev-07 unranked (0.880).
- v3c (+ c3's raises at 8 h / 5 h): ~same (7,710 / 17,213 / 3,896 / 9,460 / 4,555 / 9,590).
- v3d (+ barrier target 0.93): volume up (310 / 425 / 172 / 256 / 302 / 230 orders) but on-time 0.877-0.926, 3/6 unranked.
**Kill (parked).** The quoting side can buy volume, but our dispatch then misses the gate: the extra cars it wins go late. The limit is
knowing which cars can still be delivered on time (on-time model AUC 0.71), not the quote. Next: reverse-engineer lateness from the reveals.
